# 履歴電卓

iPhone向けのシンプルな電卓PWAです。画面内のテンキーで式を入力し、計算結果と履歴を端末内に保存できます。

## 主な機能

- 四則演算、括弧、小数、負数
- BigIntベースの10進計算（除算は小数点以下15桁で四捨五入）
- 計算履歴の再利用、式コピー、結果コピー、個別削除、全削除
- 計算式欄でのカーソル移動・数字選択
- iOS標準キーボードを表示せず、画面内テンキーで入力
- クリップボードからの貼り付け
- JSON形式での履歴書き出し
- localStorageによる履歴保存
- Service Workerによるオフラインキャッシュ

## iPhoneでの利用

1. GitHub Pagesで公開したURLをSafariで開きます。
2. 共有メニューから「ホーム画面に追加」を選択します。
3. ホーム画面に追加された「履歴電卓」を起動します。
4. 数字・演算子は画面内のテンキーで入力します。計算式欄ではタップでカーソルを移動し、ダブルタップまたは「選択」で数字を選択できます。

## GitHub Pagesへの配置

1. このフォルダ内のファイルをすべてGitHubリポジトリのルートへアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選択します。
4. Branchを `main`、Folderを `/(root)` にして保存します。
5. 公開されたURLをSafariで開きます。

`icon-192.png` と `icon-512.png` を利用する場合は、これらのアイコンファイルもリポジトリ直下に配置してください。

## データ保存とバックアップ

計算履歴はブラウザのlocalStorageに保存され、基本的に利用中の端末内に保持されます。ブラウザデータの消去や端末の故障などで失われる可能性があるため、必要に応じて「履歴を書き出す」からJSONファイルを保存してください。

## バージョン履歴

### Version 1.1.0

- iPhoneの電卓を意識したテンキー配置に変更。数字キーを左側、演算子を右側に配置。
- イコールボタンを最下段の横幅いっぱいに配置。

### Version 1.2.0

- 計算履歴から計算結果をコピーする機能を追加。
- 直近の式編集を最大100段階まで元に戻せる機能を追加。

### Version 1.3.0

- iPhone SE向けに画面レイアウトを簡素化し、不要な表示や余白を削減。
- アプリ名や説明文を削除し、バージョン番号のみ表示。
- 「元に戻す」と「バックアップ」を横並びに配置。
- 履歴の「結果を使う」機能を削除。
- 履歴から復元した式を、iOS標準キーボードを表示せず、アプリ内テンキーで編集できるように修正。
- 式表示欄を操作した際に表示される不要な警告メッセージを解消。
- 式のコピー、計算結果のコピー、バックアップ機能を改善。

### Version 1.4.0

- iPhone向けに画面上部の余白とボタン配置を調整し、操作しやすさを改善。
- 計算式の表示・編集エリアを拡大。
- iOS標準キーボードを表示せずに、計算式欄でカーソルを表示・移動できるように変更。
- 計算式欄をタップすると、その位置にカーソルを移動できるように変更。
- ダブルタップで、その位置の数字を選択できるように変更。
- 計算式欄の直下にカーソル左右移動ボタンと数字選択ボタンを追加。
- バックアップボタンの名称を「履歴を書き出す」に変更し、履歴エリアに移動。

### Version 1.5.0

- 編集操作ボタンを「↺」「◁」「▷」「選択」「貼付」の順に並べ替え。
