# 履歴電卓 PWA

iPhoneで使うことを前提にした、計算履歴の再利用に特化した電卓です。

## 主な機能

- 四則演算、括弧、負数、小数
- 10進数を `BigInt` で扱う計算エンジン（浮動小数点誤差を避ける）
- 除算結果は小数点以下15桁で四捨五入
- 履歴から式全体・結果をアプリ内コピー
- 履歴の式を長押しして一部を選択し、「選択部分をコピー」
- 入力欄のカーソル位置にアプリ内コピーを貼り付け
- iOSクリップボードからの貼り付けは別ボタン
- 履歴の削除、JSONバックアップの書き出し
- Service Workerによるオフライン利用
- 履歴はブラウザのlocalStorageに保存（最大250件）

## iPhoneへの導入

1. このフォルダの内容をGitHubリポジトリのルートへ配置してpushします。
2. GitHubリポジトリの Settings → Pages で公開元を設定します。
3. iPhoneのSafariで公開URLを開きます。
4. 共有ボタン →「ホーム画面に追加」を選びます。

HTTPSで公開してください。GitHub PagesはHTTPSに対応しています。

## 部分式コピー

1. 履歴に表示された式を長押しします。
2. iOSの選択ハンドルを動かして、コピーしたい数字や演算子を含む範囲を選択します。
3. 同じ履歴カードの「選択部分をコピー」を押します。
4. 入力欄の貼り付けたい位置をタップします。
5. 「アプリ内コピーを貼り付け」を押します。

iOSのテキスト選択UIはSafariのバージョンによって見え方が異なります。

## バックアップと復元

- 「バックアップ」ボタンでJSONをダウンロードします。
- 復元は「バックアップ」ボタンを長押し（または右クリック）してファイルを選択します。
- バックアップファイルは別の場所にも保管してください。Safariのサイトデータを消すと端末内の履歴は消えることがあります。

## 数値仕様

- 入力数値は整数部・小数部あわせて30桁以内、小数部15桁以内。
- 加減乗算は10進数で正確に計算します。
- 除算は小数点以下15桁で四捨五入します。
- カンマ区切り入力は受け付けません（例：`1234+5` と入力）。
- 1式300文字以内、最大200トークン、括弧の深さ30まで。

## 確認

`app.js` は外部ライブラリやCDNを使用しません。ネット接続なしで計算エンジンが動作します。
実際のiPhone Safariで、ホーム画面追加・選択コピー・外部貼り付け・オフライン動作を確認してください。
